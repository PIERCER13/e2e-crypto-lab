# Piercer E2E Crypto Lab (AES-GCM / HMAC / RSA)

Laboratório visual de criptografia moderna (AES-256-GCM, PBKDF2, HMAC-SHA256 e chaves RSA-OAEP)

## Funcionalidades

- **Seções principais**: Cifragem Simétrica (AES-256-GCM), Assinatura HMAC-SHA256 & Chaves Assimétricas (RSA-OAEP)
- **Ações disponíveis**: Cifrar (AES-GCM), Decifrar Payload, Calcular HMAC-SHA256, Gerar Par de Chaves RSA-2048 (JWK)
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8156`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8156`.
