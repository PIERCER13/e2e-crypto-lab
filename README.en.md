# Piercer E2E Crypto Lab (AES-GCM / HMAC / RSA)

Laboratório visual of criptografia moderna (AES-256-GCM, PBKDF2, HMAC-SHA256 and keys RSA-OAEP)

## Features

- **Main Sections**: Cifragem Simétrica (AES-256-GCM), Assinatura HMAC-SHA256 & keys Assimétricas (RSA-OAEP)
- **Available Actions**: Cifrar (AES-GCM), Decifrar Payload, calculate HMAC-SHA256, generate Par of keys RSA-2048 (JWK)
- **Multi-Language**: built-in language switcher (`PT / EN / ES`).

## How to Run

1. Run `start.bat` to start the local server on port `8156`, or open `index.html` directly in your browser.
2. Open `http://localhost:8156`.
